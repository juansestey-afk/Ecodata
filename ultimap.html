Matriz Diagnóstica de Supuestos Econométricos

Validación automática de las hipótesis de Gauss-Markov para la validez de las inferencias.

Linealidad en Parámetros ✓ CUMPLE

Prueba: Test de Ramsey RESET (F = 1.24, p = 0.289)

Recomendación: La especificación funcional es correcta. No se requiere transformación logarítmica adicional.

Normalidad de Residuos ✓ CUMPLE

Prueba: Jarque-Bera (Chi2 = 2.15, p = 0.341)

Recomendación: Los errores se distribuyen normalmente. Los intervalos de confianza son fiables.

Homocedasticidad (Varianza Constante) ✗ NO CUMPLE

Prueba: Breusch-Pagan / White (Chi2 = 14.8, p = 0.002)

Recomendación: Presencia de Heterocedasticidad. Usar errores estándar robustos de Huber-White (HC3).

Ausencia de Multicolinealidad ✓ CUMPLE

Prueba: Factor de Inflación de Varianza (VIF Medio = 1.84 < 10)

Recomendación: Las variables independientes no presentan colinealidad severa.
